# 전처리 근거 메모

주최 측 데이터 명세서와 실제 데이터 점검 결과를 대조해 내린 처리 결정을 정리한다.
(원본 데이터·행 단위 결과는 포함하지 않는다.)

## 1. 데이터 점검

| 항목 | 값 |
|---|---|
| 행 수 | 242,574 |
| 기간 | 202601 ~ 202606 (월 단위 집계) |
| 시군구 | 255개 (키 = 시도명 + 시군구명) |
| 결측 / 중복 | 0 / 0 |
| 전체 이용금액 | 17.225조 원 |
| 외국인(GENDER_CD=3) | 1조 2,781억 원 (7.42%) |

월별 합계는 1월 2.82 / 2월 2.67 / 3월 2.86 / 4월 2.83 / **5월 3.21** / 6월 2.84조 원으로
5월이 뚜렷하게 튄다. 따라서 Q2/Q1 단순 증감은 쓰지 않고, 같은 지역 내국인 증감으로
나눈 **상대성장률**을 쓴다.

## 2. 외국인 식별

명세서 `GENDER_CD` 정의: `1 남성 / 2 여성 / 3 외국인 / X 성별 NULL`,
비고에 **"외국인은 성별이 제공되지 않습니다"**라고 명시되어 있다.
즉 3은 성별 축이 아니라 별도 고객 구분값이며, 외국인에도 `AGE_CD`는 부여된다.

따라서 이 분석의 외국인 = `GENDER_CD == "3"`, 내국인 = 그 외(1/2/X) 전체로 둔다.
`X`(성별 미상)는 내국인에 포함되므로 내국인 기준선이 과소평가되지 않는다.

## 3. 업종 처리

### 3-1. 업종명 공백 제거
원본 표기에 `편 의 점`, `슈퍼 마켓`, `제 과 점`처럼 공백이 섞여 있어
`\s+` 제거 후 집계한다.

### 3-2. 갈비전문점·한정식 → 일반한식 병합
명세서 4장(업종 분류 상세)에서 **8001 일반한식 / 8002 갈비전문점 / 8003 한정식의
`TPBUZ_DT_NM`(세부업종 목록)이 완전히 동일**하다. 세 코드는 실질적으로 같은 한식
범주를 나눠 담고 있고 8002·8003은 표본이 매우 적으므로, 일반한식으로 병합한다.
임의 판단이 아니라 명세서에 근거한 처리다.

### 3-3. 분석용 업종 그룹 (5개)

| 그룹 | 포함 코드 | 명세서상 세부업종 근거 |
|---|---|---|
| 장보기 | 4020 슈퍼마켓, 4004 대형할인점 | 슈퍼마켓·마트·종합식품센터 등 |
| 한식 | 8001(+8002, 8003) | 한식 전반 |
| 카페·양식 | 8006 서양음식, 8301 제과점 | 8006에 카페·커피전문점·베이커리·디저트, 8301에 빵·떡·아이스크림 포함 |
| 중식·일식·분식 | 8005, 8004, 8021 | 8021 스넥 = 분식·김밥·떡볶이·치킨 |
| 편의점 | 4010 | 편의점 |

"카페·양식" 그룹이 도심 방문형을 가르는 핵심 축인데, 8006이 순수 레스토랑이 아니라
**카페·커피전문점을 포함**한다는 점이 이 해석의 근거다.

## 4. 행정구역

- 화성시가 **동탄구·만세구·병점구·효행구**로 분리된 신규 행정구역으로 들어와 있다.
  외부 통계(행안부·통계청)는 아직 '화성시' 단위이므로, 결합 시
  `src/regions.py`의 `SUBDIVIDED_TO_PARENT`로 되돌린 뒤 합산한다.
- 동명 시군구(예: 여러 시도의 '중구', '동구')가 있어 지역 키는 반드시
  `시도 + 시군구`를 쓴다.

## 5. 분석 대상 선정

- 외국인 소비 10억 원 미만 지역은 비중·구성비가 불안정해 제외 → 199곳
- 제주시·서귀포시는 외국인 소비의 12.3%(1,569억 원)를 차지하는 규모 이상치라
  **학습에서 빼고 벤치마크로만** 사용 → 학습 197곳
